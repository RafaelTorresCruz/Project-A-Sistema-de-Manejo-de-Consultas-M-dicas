# Project-A-Sistema-de-Manejo-de-Consultas-M-dicas



## 1.Título del proyecto

Sistema de Manejo de Consultas Médicas


## 2. descripción

El sistema está en consola. Permite al usuario registrar nuevos pacientes, atenderlos, ver el historial, ver a los pacientes en espera 
creas citas, ver las citas, buscar los médicos disponibles y ver a los médicos por especialidad.


## 3. Instalación

    Para windows:
        Requiere JDK 27
        corra el archivo run.bat

    Alternativa:
        Descargue Visual Studio Code
        Instale el Extension Pack for Java en Vs code
        Abra la carpeta
        Abra Main.java y dele a "Run"
## 4. Uso
    Tendrá un menú en el que puede acceder a las diferentes funciones del Menú.

## 5. Configuración

Las ID de los empleados son la letra según el empleo, y 5 dígitos.
Los pacientes son 6 dígitos.
